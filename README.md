# PHDS_omics_data_course

Course material for the teaching unit "Omics" of the Master's programme "Public Health Data Science" at the University of Bordeaux.

## Contents

- `slides/`: lecture slides
- `practicals/`: practical sessions as R Markdown, with `questions/` and `solutions/` versions
- `examples/`: R scripts used to generate the demonstration figures shown in the slides

## Usage

Open `PHDS_omics_data_course.Rproj` in RStudio so that paths are relative to the project root. The data used in the practicals and examples are not stored in this repository; place them in a `data/` folder at the project root (this folder is git-ignored). Generated figures are written to `figures/`.

Each practical installs and loads the R and Bioconductor packages it needs.
